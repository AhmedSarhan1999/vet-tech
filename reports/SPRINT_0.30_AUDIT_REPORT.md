### 1. ЦЕЛИ И ЗАДАЧИ СПРИНТА 0.30
1. **Тотальное подавление артефактов десктопного скроллбара (Scrollbar Suppression):**
   - Ликвидация серых горизонтальных полос прокрутки (desktop scrollbar tracks) во всех каруселях, фильтр-пиллах, сегментированных контроллерах и пресетных блоках.
   - Внедрение универсальных утилит подавления скролла на уровне CSS (`src/index.css`) и Tailwind-классов (`scrollbar-none`, `no-scrollbar`, `[&::-webkit-scrollbar]:hidden`, `[-ms-overflow-style:none]`, `[scrollbar-width:none]`, `touch-action: pan-x`).

2. **Полноэкранная навигация в чатах (Full-Page Chat Navigation):**
   - Полный вывод из эксплуатации плавающих модальных окон (Modal Popups) для диалогов теле-курации (`DoctorChatRoomModal.tsx`).
   - Реализация нативного перехода на отдельный экран (`full-page view takeover`) внутри мобильного контейнера при сохранении состояния родительского списка без перезагрузок.
   - Добавление нативного фиксированного хедера (`ArrowLeft` назад к списку, имя и порода пациента, возраст/вес, номер чипа, MTS Exolve прокси-телефон владельца, бейдж дежурной курации).
   - Скрытие нижней панели навигации доктора (`DoctorShell`) в момент нахождения внутри активного чата для эргономичного размещения поля ввода сообщений внизу экрана.

3. **Строгое удержание мобильного вьюпорта телемедицины (Viewport Confinement):**
   - Локализация экрана видеоконсультации (`VideoConsultationRoomScreen.tsx`) и WebRTC оверлеев строго внутри центрального мобильного контейнера (`max-w-[440px] mx-auto`).
   - Устранение неконтролируемых глобальных прорывов разметки (`fixed inset-0`, `w-screen`, `h-screen`), приводящих к растягиванию интерфейса на весь монитор.

### 2. ВЫПОЛНЕННЫЕ АРХИТЕКТУРНЫЕ МОДИФИКАЦИИ

#### 2.1. Глобальные CSS-правила скроллбара (`src/index.css`)
- Объявлены кросс-браузерные правила полного скрытия треков и ползунков для WebKit/Blink (Safari, Chrome, Edge), Gecko (Firefox) и Trident:
  - `::-webkit-scrollbar { display: none !important; width: 0px !important; height: 0px !important; }`
  - `-ms-overflow-style: none !important;`
  - `scrollbar-width: none !important;`
- Зарегистрированы вспомогательные селекторы `.scrollbar-none`, `.no-scrollbar` и атрибут `[data-no-scrollbar]`.

#### 2.2. Нативный полноэкранный чат врача (`src/features/doctor/DoctorChatRoomModal.tsx`)
- Ликвидирован полупрозрачный затемняющий оверлей и всплывающая карточка модального окна.
- Реализована корневая разметка полностраничного вьюпорта: `absolute inset-0 z-40 bg-white flex flex-col w-full h-full overflow-hidden select-none font-sans`.
- Построен нативный мобильный хедер:
  - Кнопка возврата с SVG-иконкой `ArrowLeft` и доступной меткой `aria-label`.
  - Заголовок с кличкой пациента, породой, возрастом и массой тела.
  - Микро-чип с номером микрочипа ГОСТ/ISO (`ISO 643098100234567`).
  - Данные владельца с кликабельным прокси-номером телефонии MTS Exolve (`Phone`).
  - Пульсирующий индикатор активного телемедицинского дежурства (`Курация 22:00`).
- Быстрые шаблоны клинических ответов снабжены горизонтальным скроллом без визуальных полос прокрутки.
- Просмотрщик фотофиксации (Photo Zoom) заключен в границы мобильного экрана (`absolute inset-0 z-50 bg-slate-900/80`).

#### 2.3. Интеграция и удержание вьюпорта в хабе чатов (`src/features/doctor/DoctorChatsScreen.tsx`)
- Добавлен коллбек `onChatOpenChange?: (isOpen: boolean) => void`.
- Добавлено локальное состояние выбранного чата `selectedChatId`.
- Полноэкранный рендеринг чата активируется при выборе карточки пациента и возвращает список при клике `onClose`.
- Все горизонтальные фильтр-бары (сегментированные табы "Все обращения / Назначения / ВетИС / Архив", фильтры видеосессий "Все / Сегодня / Завтра / Завершенные") переведены на suppressed-scrollbar с поддержкой плавного свайпа.
- Встроенные диалоги переноса слотов видеозвонка, инспекции карточки пациента, арбитражного возврата YooKassa и панели теле-куратора переведены с `fixed` на `absolute inset-0 z-50 ... max-w-[440px] mx-auto`.

#### 2.4. Динамическое скрытие нижней панели навигации (`src/features/doctor/DoctorShell.tsx`)
- Введено реактивное состояние `isChatOpen`.
- При открытии любого диалога нижняя 5-вкладочная панель навигации врача (`<nav aria-label="Навигация врача">`) скрывается, освобождая пространство для клавиатуры и панели ввода сообщений со штампом УКЭП.
- При выходе из диалога панель плавно возвращается на экран без скачков контента.
- При переключении основных вкладок состояние `isChatOpen` сбрасывается в исходное.

#### 2.5. Локализация видеокомнаты телемедицины (`src/features/telehealth/VideoConsultationRoomScreen.tsx`)
- Корневой контейнер экрана видеосвязи переведен из `h-screen w-full` в `relative w-full h-full min-h-[100dvh] md:min-h-0 bg-slate-950 text-white flex flex-col overflow-hidden select-none font-sans max-w-[440px] mx-auto`.
- Всплывающие уведомления (тосты переключения микрофона, камеры, добавления рецепта) переведены из `fixed` в `absolute top-16 inset-x-4 z-50`, исключая их выпадение за границы мобильного телефона на десктопных мониторах.
